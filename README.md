# Remix Trigonometri X (Web App)

Multimedia Interaktif Pembelajaran Matematika SMA Kelas X Materi Trigonometri oleh **YULIANTO HARSONO**.

Aplikasi web responsif yang dapat dibuka melalui browser di smartphone Android, iOS, tablet, maupun komputer/laptop.

## Fitur Utama

1. **Login Siswa**: Identitas siswa meliputi Nama Lengkap, Kelas, dan Nomer Absen.
2. **Materi Trigonometri**: 5 Bab lengkap dengan uraian konsep, rumus pokok, dan contoh pembahasan terbimbing:
   - 1. Definisi Perbandingan Trigonometri pada Segitiga Siku-Siku
   - 2. Sudut-Sudut Istimewa (0°, 30°, 45°, 60°, 90°)
   - 3. Sudut Berelasi di 4 Kuadran (Aturan Tanda & Sumbu Kartesius)
   - 4. Identitas Dasar Trigonometri (Teorema Pythagoras)
   - 5. Aplikasi Klinometer & Sudut Elevasi
3. **Simulasi Klinometer Interaktif**:
   - Visualisasi kanvas grafis interaktif pengamat mengukur tinggi pohon kelapa
   - Slider real-time untuk sudut elevasi (15°–75°), jarak horizontal (5m–35m), dan tinggi pengamat (1.2m–2.0m)
   - Tombol preset sudut istimewa lapangan (30°, 45°, 60°)
   - Mini-game misi tantangan pencapaian target ketinggian pohon
4. **Evaluasi 10 Soal HOTS (High Order Thinking Skills)**:
   - Pilihan ganda A–E berorientasi AKM & kontekstual
   - Diagram matematis dan sketsa geometris interaktif untuk butir soal 1–5
   - Pembahasan langkah demi langkah untuk setiap nomor
5. **Data Sheet Nilai Siswa & Analitik**:
   - Penyimpanan riwayat pengerjaan nilai kuis
   - Grafik batang akurasi per butir soal (S1–S10)
   - Diagram lingkaran kelulusan KKM (75)
   - Garis tren riwayat capaian nilai
   - Ekspor dan unduh rekapitulasi nilai dalam format CSV
6. **Tentang Pengembang**: Profil Guru Pengampu Yulianto Harsono dan capaian sasaran pembelajaran Fase E Kurikulum Merdeka.

## Teknologi

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Lucide React
- HTML5 Canvas untuk visualisasi geometri dan simulasi klinometer
